# SolarPunk Kyrgyzstan — Future Paths

A branching decision simulator for the SolarPunk hackathon.

You advise Kyrgyzstan. Every choice changes statistics (literacy, debt, energy independence, nature, happiness, tourism, economy, culture). After each 3-year jump you see the new numbers. Critical thresholds end the game. Later choices can partially repair earlier damage.

## Features
- English / Russian
- Visible before/after style stats
- Lose conditions (debt ≥ 200% GDP, literacy ≤ 70, nature ≤ 15, happiness ≤ 20)
- Browser-only, no build step
- Deployable on GitHub Pages

## Run locally
Just open `index.html` in a browser.

## Deploy
Push to GitHub and enable GitHub Pages on the main branch.
