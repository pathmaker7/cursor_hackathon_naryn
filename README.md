# SolarPunk Kyrgyzstan — Future Paths

Evidence-based branching decision simulator for the SolarPunk hackathon.

Starts in **early 2026** with realistic Kyrgyzstan baselines (literacy ~99%, national poverty ~25%, public debt ~40% of GDP, energy self-sufficiency ~79%, forest cover 6.4%).

## Features
- English / Russian
- Live stats with stickers (genius/dumb for education, red currency for high debt, nature icons, etc.)
- Traditional Kalpak visual that becomes more beautiful as the country prospers
- 3-year jumps with visible consequences
- Danger-zone lose conditions (debt, literacy, nature, happiness)
- Local leaderboard (highest scores saved in browser)
- Browser-only, no build step

## Run
Open `index.html` in any browser.
